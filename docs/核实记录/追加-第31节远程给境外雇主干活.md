## 定级与取舍

- 定 A：四份都是可逐字核对的法规原文，判定链条完整——劳务提供地在境内（实施条例第三条第一项）→ 属境内所得 → 支付方在中国境内无机构、扣缴落不了地 → 触发个税法第十条第二项自行申报 → 收汇按经常项目非经营性结汇、走第十条第七项「职工报酬」。
- **口径与量级**：口径记金钱。收益量级判「中」，**不是机械套阈值套出来的**——这条换回的不是具体金额，而是「别漏报、别在收汇上被卡住」，金额阈值套不上，故用判断定「中」，依据记于此。成本：钱 0、时间中（一年一次汇算清缴，加上银行材料）、毅力些，按阈值落性价比一般档。
- **这条最反直觉的一点**：普通人以为「给境外公司干活＝境外所得」，实际按劳务提供地判定是**境内所得**，境外所得抵免那一套（财政部 税务总局公告 2020 年第 3 号）用不上，无住所个人境外所得免税那套（实施条例第四条）也用不上。正文把这层写进了「说人话」。
- **没写的四项**（都可能有实际成本，但本轮找不到可逐字核对的依据，宁可不写）：① 这笔收入要不要缴增值税、要不要代开发票；② 长期这样做要不要办营业执照或登记为个体户；③ 能不能按劳动法向境外雇主主张权利（年假、加班费、解除补偿）；④ 数据出境与保密。正文备注里把这四项列明，避免读者以为已经覆盖。

## 读者提的「境外雇主要求雇员必须具备本国国籍」

**未采用，正文一个字都不写这个说法**（合并后订正：原来正文备注里写了「网上流传的『……必须是本国国籍』，本书没有找到可核对的官方依据，不写」，这是先引一句读者没见过的说法再去评价它，和「说人话」里被禁的「『XX』不是瞎编」是同一个毛病，已删）。检索到的情况：美国出口管制里的 `U.S. person`（公民、合法永久居民、受难民或庇护者）确实会让部分受控技术岗位实际上不招外国人，但那是出口管制「视同出口」的结果，不是一条「雇主必须雇本国人」的劳动法规则，且材料讲的都是**在美国境内受雇**时向外国人披露受控技术的情形，与「人坐在中国境内远程干活」对不上。**更要紧的是，检索到的全部是律所分析文章（Covington、Pillsbury 等），没有一份 ITAR/EAR 原文或 BIS/DDTC 官方口径**，按项目引用规则不得引用，故不写入正文。若日后要收，需先取到 eCFR 上的 ITAR（22 CFR 120.62 等）与 EAR（15 CFR 772.1）原文再定。

## 合并后订正（2026-09-20）：税目定成「劳务报酬」是错的

原条目的「说人话」写「按劳务报酬在境内交个税」，收益栏也只引了实施条例第六条第（二）项的劳务报酬定义。这一步不成立：

- 实施条例第六条第（一）项写的是「工资、薪金所得，是指个人因**任职或者受雇**取得的工资、薪金、奖金……」（已复核 <https://www.gov.cn/zhengce/zhengceku/2018-12/22/content_5351177.htm>，逐字比对）。条目标题就叫「给境外**雇主**干活」，正文还让读者拿**雇佣合同**去银行按「职工报酬」结汇，却按劳务报酬报税，内部自相矛盾。
- 而条目自己在备注里承认「境外雇主与远程干活的人之间算什么关系……找不到可逐字核对的依据」——关系既然没定性，税目就更不能断言。
- 这不是措辞问题，落到钱上：个税法第六条只给劳务报酬、稿酬、特许权使用费三项减除 20% 费用后计入收入额，工资薪金不在其内（已复核国家税务总局政策法规库 <https://fgk.chinatax.gov.cn/zcfgk/c100009/c5193028/content.html>，2018 年第七次修正版第六条），同样一笔收入按两个税目算出来的税不一样。

改法：说人话改成「并进当年综合所得、在境内自己申报」，税目按「签雇佣合同、听对方安排 = 工资薪金 / 自己按项目接活交付 = 劳务报酬」分写一句，并点明劳务报酬只按收入的八成计入；收益栏补引实施条例第六条第（一）项与个税法第六条两句原文，来源栏的个税法条号补第六条、加一条税务总局政策法规库链接。备注里「没写的四项」第 ③ 项同步收窄为「能不能按劳动法向境外雇主主张权利」，不再和税目定性混在一起；「本轮」这种仓库工作流的词改掉。原判定链条（劳务提供地在境内 → 境内所得 → 无扣缴义务人 → 自行申报 → 结汇走「职工报酬」）不受影响，仍然成立。
